# koryxa-services-ia

Produit autonome **Services IA** de l'écosystème KORYXA.

## Contenu

- `frontend/` — interface Next.js extraite du site KORYXA.
- Pages principales : `/services`, `/services/[pillar]`, `/services/[pillar]/[service]`.

## Démarrage

```bash
cd frontend
npm install
npm run dev
```

Ce dépôt héberge le produit autonome KORYXA Service IA & Web.
